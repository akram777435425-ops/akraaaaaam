# Archive System - Professional Document Management

نظام إدارة الأرشيف الاحترافي

## نظرة عامة

تطبيق نظام إدارة الأرشيف الاحترافي المبني بلغة Python، يوفر حلاً متكاملاً لإدارة المستندات والملفات
مع ميزات أمان متقدمة، نسخ احتياطية تلقائية، وتدقيق شامل.

## الميزات الرئيسية

### 1. إدارة المستندات
- تحميل وتخزين المستندات
- تنظيم المستندات في فئات
- البحث والفرز المتقدم
- أرشفة واستعادة المستندات

### 2. الأمان
- المصادقة الآمنة مع التشفير
- التحكم بالوصول القائم على الأدوار
- تتبع جميع العمليات (Audit Logging)
- حماية من الهجمات الشائعة

### 3. النسخ الاحتياطية
- النسخ الاحتياطي التلقائي
- استعادة من النسخ الاحتياطية
- إدارة الاحتفاظ بالبيانات
- ضغط وتشفير البيانات

### 4. الإدارة والمراقبة
- لوحة تحكم شاملة
- تقارير مفصلة
- سجلات نشاط شاملة
- إدارة المستخدمين والأدوار

## المتطلبات

- Python 3.9+
- tkinter (GUI)
- sqlite3 (Database)
- bcrypt و cryptography (Security)

## التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/akram777435425-ops/akraaaaaam.git

# التنقل للمجلد
cd ArchiveSystem

# تثبيت المتطلبات
pip install -r requirements.txt
```

## الخدمات المتاحة

### AuthService
خدمة المصادقة والتفويض

### DocumentService
خدمة إدارة المستندات

### BackupService
خدمة النسخ الاحتياطية والاستعادة

خدمة التدقيق والتتبع
